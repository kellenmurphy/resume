# resume

Canonical source for Kellen J. Murphy's resume. All published formats are
generated from a single data file, [`resume.yaml`](resume.yaml):

| Format | Generated by | Published to |
| --- | --- | --- |
| `resume.tex` → `resume.pdf` | `templates/resume.tex.j2` + [xu-cheng/latex-action](https://github.com/xu-cheng/latex-action) | [kellenmurphy.com/resume.pdf](https://kellenmurphy.com/resume.pdf) |
| `resume.html` | `templates/resume.html.j2` | [kellenmurphy.com/resume.html](https://kellenmurphy.com/resume.html) |
| `resume.md` | `templates/resume.md.j2` | [kellenmurphy.com/resume.md](https://kellenmurphy.com/resume.md) |

**Edit `resume.yaml`, never the generated outputs.** The HTML and Markdown
files in the [kellenmurphy.com](https://github.com/kellenmurphy/kellenmurphy.com)
repo are overwritten by CI on every push to `main` here.

## Building locally

Requires Python 3 with `pyyaml` and `jinja2`:

```bash
pip install -r scripts/requirements.txt
python3 scripts/build.py
```

Outputs land in `build/` (gitignored). To compile the PDF, use
[Docker](https://docs.docker.com/get-docker/):

```bash
docker run --rm -v "$(pwd)/build:/workdir" -w /workdir ghcr.io/xu-cheng/texlive-full pdflatex resume.tex
```

Output: `build/resume.pdf`

## CI

On every push to `main`, a GitHub Actions workflow:

1. Renders `resume.tex`, `resume.html`, and `resume.md` from `resume.yaml`
   (the HTML page's `last_modified_at` is set to the commit date)
2. Builds `build/resume.pdf` from the rendered LaTeX
3. Uploads all formats as a workflow artifact (Actions tab → latest run → **Artifacts**)
4. Pushes `resume.pdf`, `resume.html`, and `_md_pages/resume.txt` to
   [kellenmurphy.com](https://github.com/kellenmurphy/kellenmurphy.com), whose
   Jekyll deploy workflow publishes them
